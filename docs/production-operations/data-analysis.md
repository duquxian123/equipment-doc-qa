# 生产运营沙盘：数据分析说明

> 预置数据集包含 24 笔程序生成的铝卷生产订单，仅用于展示统计分析和应用流程。

## 1. 数据字段

| 类别 | 字段 |
| --- | --- |
| 订单 | 客户、合金、厚度、数量、交期、优先级 |
| 工单 | 产线、下发时间、完成时间 |
| 生产 | 投入重量、合格产出、废品、能耗、停机、班次、操作员 |
| 质量 | 合格/不合格、缺陷类型、质检员 |
| 成本 | 材料成本、能耗成本、停机成本、总成本、吨成本 |
| 库存 | 成品入库、废品入库 |

## 2. 看板指标

- 累计订单数和各状态订单数；
- 累计投入、合格产出和废品吨数；
- 综合良率；
- 合格吨平均成本；
- 实际成本与计划成本偏差；
- 成品库存和废品库存；
- 按产线聚合的产出、良率和平均停机时间；
- 缺陷类型分布；
- 最近 14 个生产日期的产出趋势。

## 3. 分析原则

1. 先用业务字段分组，再做图形展示。
2. 产量、良率和成本分别计算，不用订单数代替生产规模。
3. 单位成本按合格产出计算，不按投入量计算。
4. 缺陷记录同时保留订单和工单关联，便于追溯到生产班次。
5. 看板结论只描述当前模拟数据，不外推为真实行业结论。

## 4. 页面可以回答的问题

- 哪条产线当前良率较低？
- 哪些缺陷出现次数最多？
- 生产规模变化时，成本和停机是否同步变化？
- 一笔订单为什么实际成本高于计划成本？
- 出现厚度超差时，应去查哪类设备维护或工艺规范？

## 5. 局限

- 24 笔数据不足以做统计显著性分析。
- 没有季节、客户、设备和批次层级等真实工业特征。
- 当前只做描述统计，不包含预测或机器学习。
- 所有数据均由程序生成，不能用于真实经营决策。
