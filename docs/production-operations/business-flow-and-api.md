# 生产运营沙盘：业务流程与接口

> 本文描述 EquipmentDoc QA 中的模拟 ERP/MES 业务闭环。所有订单和生产数据均由程序生成，不连接真实企业系统。

## 1. 演示场景

模拟一家铝卷加工厂完成一笔订单：

1. ERP 创建客户销售订单，记录合金、厚度、数量、交期和计划成本。
2. ERP 将订单下发到 MES，生成唯一生产工单并指定产线。
3. MES 完成生产后，回传投入量、合格产出、废品、能耗、停机、班次和质检结果。
4. ERP 更新订单状态、成品库存、废品库存和成本快照。
5. 运营看板聚合良率、缺陷、产线和成本数据。
6. 出现质量缺陷时，可把相关问题带入现有设备文档 RAG 问答。

```mermaid
flowchart LR
    A["ERP<br/>销售订单"] -->|下发工单| B["MES<br/>生产执行"]
    B -->|产量与质检回报| C["ERP<br/>成本与库存"]
    C --> D["运营看板"]
    D -->|异常问题| E["设备文档问答"]
```

## 2. 状态约束

| 当前状态 | 允许动作 | 下一状态 |
| --- | --- | --- |
| `planned` 待下发 | ERP 下发生产工单 | `dispatched` |
| `dispatched` 生产中 | MES 提交生产和质检结果 | `completed` |
| `completed` 已完成 | 只读查看 | `completed` |

关键规则：

- 一个销售订单最多对应一个生产工单。
- 重复下发会被拒绝，避免生成重复生产任务。
- 只有已下发工单可以报工。
- 同一工单只能报工一次。
- 合格产出与废品重量之和不能超过投入重量。
- 质检不合格时必须填写缺陷类型。

## 3. 接口清单

| 方法与路径 | 作用 | 模拟系统边界 |
| --- | --- | --- |
| `GET /ops/dashboard` | 返回看板指标、缺陷和产线分析 | 数据平台 |
| `GET /ops/orders` | 返回订单队列 | ERP |
| `GET /ops/orders/{id}` | 返回订单、工单、生产、质量和成本详情 | ERP/MES 联合视图 |
| `POST /ops/orders` | 创建销售订单 | ERP |
| `POST /ops/orders/{id}/dispatch` | 下发并生成 MES 工单 | ERP → MES |
| `POST /ops/work-orders/{id}/complete` | 提交生产与质检结果并结算 | MES → ERP |

所有接口使用项目现有登录会话。普通用户可以查看看板，知识管理员或系统管理员可以创建、下发和报工。

## 5. 成本计算

当前演示使用固定模拟单价：

- 材料：18,500 元/吨；
- 电费：0.72 元/kWh；
- 停机损失：8.5 元/分钟。

计算公式：

```text
材料成本 = 投入重量(kg) / 1000 × 材料单价
能耗成本 = 能耗(kWh) × 电费单价
停机成本 = 停机分钟 × 每分钟损失
总成本 = 材料成本 + 能耗成本 + 停机成本
吨成本 = 总成本 ÷ 合格产出吨数
成本偏差 = 实际总成本 - 计划成本
良率 = 合格产出 ÷ 投入重量 × 100%
```

这些单价仅用于技术演示，不能视为企业真实成本口径。

## 6. 数据与事务一致性

报工写入生产、质量、成本、库存和集成事件时，使用同一个 SQLite 事务。任一写入失败时整笔事务回滚，避免出现“生产已记录但成本没有更新”的半完成状态。

## 7. 已知边界

- 没有实现真实 ERP/MES 网络服务拆分，只通过独立接口和数据表模拟系统边界。
- 没有接入 SAP、用友、金蝶或真实设备采集。
- 没有处理复杂批号、多工序、返工、报废审批和财务凭证。
- 当前成本为演示口径，不包含人工、折旧、税费和管理费用。
- 所有数据均为合成数据，不来自任何真实企业。
